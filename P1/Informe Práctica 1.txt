Informe Práctica 1:

   Introducción:

	        En esta práctica realizamos una medición empírica de los tiempos de ejecución de dos funciones que buscan
	    la resolución del problema de la suma de la subsecuencia máxima, comparando su implementación y determinando
	    su complejidad computacional.

        La primera función tiene una complejidad cuadrática 0(n^2), posteriormente demostrada, y la segunda una complejidad lineal O(n).

    Características del ordenador usado para la medición de tiempos:
    
        Ordenador:Vivobook_ASUSLaptop X1504VA_F1504VA
        S.O: Linux, 6.8.0-41-generic
        Compilador: gcc (Ubuntu 13.2.0-23ubuntu4) 13.2.0
        CPU: 13th Gen Intel(R) Core(TM) i7-1355U
        Memoria RAM: 16Gb
        Unidades de tiempo: microsegundos (µs)

    Metodología:
            Para determinar la complejidad empírica de los algoritmos, medimos el tiempo de ejecución t(n) para diferentes tamaños de entrada
        n y calculamos los cocientes t(n)/f(n) para diferentes funciones f(n) que representan distintas complejidades.
        Resumiendo:
            ·Si t(n)/f(n) -> infinito, entonces f(n) es una cota subestimada (complejidad real mayor).
            ·Si t(n)/f(n) -> 0 cuando n -> infinito, entonces f(n) es una cota sobrestimada (complejidad real menor).
            ·Si t(n)/f(n) -> constante cuando n -> infinito, entonces f(n) representa la complejidad real del algoritmo.

    Conclusiones:
            Para el primer algoritmo (sumaSubMax1) es cuadrática, confirmando el analisis teórico.
            Para el segundo algoritmo (sumaSubMax20) es lineal, confirmando asi el analisi teórico.

        volumen de datos.
            Además, la metodología empleada mediante cocientes t(n)/f(n) resulta efectiva para determinar complejidades empíricas.
