Informe Práctica 2:

    Introducción: 

            En esta práctica estudiamos el comportamiento de dos algoritmos de ordenación: Ordeación por Inserción
        y ordenación Shell. El objetivo es realizar una comparación entre el rendimiento de ambos 
        además de determinar sus complejidades.
        
        El caso medio de la ordenación por inserción posee una complejidad cuadrática O(n^2) en cambio la ordenación Shell muestra
        una mejora con respecto al algoritmo anterior mediante el uso de secuencias de incrementos que reducen 
        la cantidad de comparaciones y movimientos. Las secuencias empleadas son las siguientes:

        -Hibbard-> 2^k − 1: (1, 3, 7, 15, 31, 63, 127, ...)
        -Knuth-> (3^k − 1)/2: (1, 4, 13, 40, 121, 364, 1093, ...) 
        -Sedgewick-> 4^k + 3 × 2^(k−1) + 1 para k ≥ 1: (1, 8, 23, 77, 281, 1073, 4193, ...)
        -Ciura-> (1, 4, 10, 23, 57, 132, 301, 701, 1750) Redondeo con la multiplicacion del ultimo valor por 2.25

    Metodología:
            Para determinar la complejidad empírica de los algoritmos, medimos el tiempo de ejecución t(n) para diferentes tamaños de entrada
        n y calculamos los cocientes t(n)/f(n) para diferentes funciones f(n) que representan distintas complejidades. Resumiendo:

            ·Si t(n)/f(n) -> infinito, entonces f(n) es una cota subestimada (complejidad real mayor).

            ·Si t(n)/f(n) -> 0 cuando n -> infinito, entonces f(n) es una cota sobrestimada (complejidad real menor).

            ·Si t(n)/f(n) -> constante cuando n -> infinito, entonces f(n) representa la complejidad real del algoritmo.

Conclusiones:
    Para el algoritmo de Ordenación por Inserción podemos describir dos casos:
        · El algoritmo tendrá una complejidad lineal en el caso de que el vector este ordenado ascendentemente.
        · El algoritmo tendrá una complejidad cuadrática en el caso de que el vector este ordenado descendentemente o este desordenado.
    Para el algoritmo de Ordenación por Shell:
        · Este algoritmo describe una complejidad cuadrática para los tamaños probados empíricamente.
        · Aún así, podemos observar que las secuencias Knuth y Ciura muestran un rendimiento ligeramente superior.
    Por último, podemos destacar que para vectores prácticamente ordenados, la Ordenación por Inserción es muy eficiente, pero para datos
    totalmente desordenados, la Ordeación por Shell ofrece un mejor rendimiento.
